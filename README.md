# People Analytics: Employee Attrition & Satisfaction Modeling

## Overview
A Python-based data analysis project evaluating key drivers of turnover, overtime impact, and satisfaction metrics within enterprise teams.

> **Note:** Dataset is synthetic and created for portfolio demonstration purposes.

## Insights & Findings
* Identified high overtime hours as the primary driver for attrition in high-performing roles.
* Developed predictive filters to flag high-risk employee segments early.

## Tech Stack
* **Language:** Python (Pandas, NumPy)
* **Environment:** VS Code / Jupyter
